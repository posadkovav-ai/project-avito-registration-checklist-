# project-avito-registration-checklist-
# Проект: Чек-лист для тестирования регистрации на Avito

## Описание проекта
Разработка и выполнение чек-листа для тестирования процессов регистрации и верификации на сайте **Avito.ru**.

## Цель
Обеспечить качественное тестирование всех сценариев регистрации:
- Создание аккаунта по номеру телефона
- Выбор типа профиля (личный / бизнес)
- Верификация через Госуслуги, банки, паспорт
- Настройка профиля

## Как использовать
1. Скачайте файл `docs/checklist.xlsx`
2. Откройте в Excel или Google Sheets
3. Выполняйте проверки последовательно
4. Заполняйте колонки "Фактический результат" и "Статус"
5. При обнаружении бага — создайте баг-репорт
